# Versus Faces (mod de Geode)

Compilar: `cmake -B build && cmake --build build --config RelWithDebInfo` (con GEODE_SDK definido).
Multijugador: `node server/server.js` y pon la URL en los ajustes del mod (para jugar por internet, hospedalo o usa un tunel).
Anade `logo.png` (336x336) si quieres icono en la lista de mods.
